    2. Методика и формулы

    Для каждого этапа j задано плановое распределение p_j и скорректированное априорноa_j:

    Шаг 1 (план):          B_plan = Σ B_j, где B_j = round(B * p_j)
Шаг 2 (коррекция):      a'_j = a_j * (1 + κ · r_j)
Шаг 3 (нормировка):      a_j = a'_j / Σ a'_k
Шаг 4 (реальный бюджет): B_act = round(B · (1 + κ · γ_s))
Шаг 5 (факт):           F_j = round(B_act · a_j)

    Отклонения и метрики:

    Δ_j = F_j - B_j
MAD = (1/n) Σ |Δ_j|
TV = 0.5 · Σ |p_j - a_j|
KL(P||A) = Σ p_j · ln(p_j / a_j)
H(A)= -Σ a_j·ln(a_j)  (нормированная энтропия)
