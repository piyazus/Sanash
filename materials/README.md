# Sanas: материалы

Здесь собраны демонстрационные и медиафайлы, которые не являются исходным кодом,
Ground Truth или доказательством качества системы.

## BudgetAware visual demo

`budgetaware_sanash_demo/` — статическая научно оформленная демонстрация
объяснимого budget-aware распределения.

- Публичная версия: <https://budgetaware-sanash-demo.vercel.app>
- Локальный исходник: [`budgetaware_sanash_demo/index.html`](budgetaware_sanash_demo/index.html)

Для работы открыть `index.html`, нажать **Запустить BudgetAware**, затем
переключать сценарии. Экран показывает план и факт, метрики их сходства и
журнал действий алгоритма.
