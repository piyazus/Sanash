# Sanas: current state

Этот файл оставлен как совместимая точка входа для старых ссылок.

**Актуальный и единственный Ground Truth находится в
[`GROUND_TRUTH.md`](GROUND_TRUTH.md).**

Причина замены: прежний `STATE.md` смешивал решения, гипотезы и измерения,
ошибочно называл полный Gorelik dataset скачанным и применял слишком грубое
правило «append-only log всегда побеждает». Исторический log содержит
несколько отменённых архитектур и не может сам быть current-state snapshot.

Перед любой работой прочитать `GROUND_TRUTH.md`, затем проверить `git status`.
