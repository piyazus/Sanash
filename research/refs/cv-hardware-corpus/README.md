# CV/hardware corpus — ceiling-RGB device track

44 PDFs, added 2026-08-26, triaged by the refgraph skill from a 56-file
batch dropped in the project root. Full classification with reasons for
every file (including the 12 rejected/duplicate) is in
`research/refs/REFGRAPH_REPORT.md`.

Scope: crowd-counting model literature (CSRNet, PFCASA, CORN, DINOv2 and
general CNN/attention/transformer crowd-density methods), APC sensor
comparators (stereovision, ToF, thermal, video-based), edge-hardware
deployment studies (Jetson Nano, NPU platforms), and one data-interchange
standard (VDV 457). This is device/model-selection literature for the
CV track, separate from the RTCI behavioral corpus in
`research/refs/rtci-supporting/` and `rtci_paper_inventory.csv`.

None of these are verified-for-citation in the paper draft sense used by
research-writer's citation rules. This is triage: relevant enough to keep
on disk for the model/hardware comparison Donatello and CADy need to do,
not yet read in full or cited anywhere.
