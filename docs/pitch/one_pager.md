# Sanas — проект на одной странице

**Что это.** Система, которая показывает пассажиру в приложении Avtobys,
насколько заполнен автобус, ещё до его прихода на остановку: 5 уровней,
от "свободно" до "битком".

**Проблема.** Пассажир видит в приложении, где автобус, но не знает,
влезет ли он в него. Автобус приходит битком, поездку нельзя было
спланировать. Перевозчик и город при этом не имеют объективной картины
заполняемости по остановкам и времени.

**Решение (Фаза 1).** Над каждой дверью — маленький датчик-дальномер
(не камера; принцип как у парктроника, 64 луча сеткой 8×8). Он замечает,
что под ним прошёл человек, и в какую сторону. Вошёл — счётчик +1,
вышел — минус 1, на конечной сброс в ноль по GPS. Бортовой блок переводит
счёт в один из 5 уровней и отправляет на сервер Avtobys.

**Приватность по конструкции.** Датчик выдаёт 64 числа-расстояния.
Изображение не существует физически — восстановить лицо, одежду или
личность не из чего. В Фазе 1 камер нет вообще.

**Что уже сделано.**
- Алгоритм счёта написан и прошёл первую валидацию на записях из
  настоящего автобуса (публичный датасет Gorelik et al., Германия):
  симуляция нашего 8×8 датчика поймала **24 из 25** событий
  посадки/высадки, направление верно во всех 24 пойманных, **0 ложных
  срабатываний**, средняя ошибка счётчика салона **0,17 человека**.
  Честная оговорка: всего 25 событий — это проверка работоспособности,
  не сертификация точности.
- Отброшен по измерениям неработающий вариант "камера глубины в салоне
  считает всех": покрытие 10% площади, корреляция с реальным числом
  людей 0,18. Решения выбираем по данным.
- Спроектировано железо: 2 дверных узла (датчик + ESP32-S3), бортовая
  шина CAN, шлюз с GPS-сбросом и LTE. Список компонентов и схемы готовы.

**В работе.** Закупка компонентов, сборка первого узла, проверка
настоящего датчика на столе (до сих пор он был в симуляции).

**Планируется.** Пилот на реальном автобусе с записью собственных данных
(публичные датасеты юридически непригодны для коммерческой версии).
Фаза 2 — одна RGB-камера в салоне с нейросетью для поправки счёта на
длинных маршрутах: спроектирована, НЕ обучена, ждёт доступа к автобусу и
отдельного разрешения на камеры.

**Экономика компонентов.** Класс цены датчика — единицы долларов за чип
при объёме (точная закупочная цена — [нужна реальная цифра]); стоимость
комплекта на автобус — [нужна реальная цифра: цены компонентов
собираются, см. docs/trade_study.md].

**Чего просим.**
1. Доступ к одному автобусу для установки узла и записи данных.
2. Технический контакт по API Avtobys (куда слать уровень).
3. Вместимость моделей автобусов парка (для перевода счёта в уровни).
4. LOI от Innoforce/Avtobys — необязывающее, для грантов и акимата.
