# Результат: разметка кадров и сравнение разметчиков

12 сентября 2026. Статус: **реализовано и проверено на искусственных данных**.

## Что работает

Локальный [разметчик кадров](../../development/experiments/artifacts/video-intake/demo-20260912/annotate.html)
показывает подготовленные изображения и позволяет отмечать людей кликами.
Для каждой точки сохраняются нормированные координаты, зона салона, поза и
видимость. Присутствие человека по видимым частям тела отмечается отдельно
от полной/частичной видимости головы. Полностью скрытые люди не размечаются.

Есть отмена последней отметки, замечания о слепых зонах, подтверждение кадра,
сохранение черновика в браузере, скачивание JSON и восстановление из него.
Начните с отдельного ID, например R1; второй разметчик использует R2 и работает
независимо. При смене ID или импорте приложение просит сначала скачать
несохранённую в файл работу. Один ID не может импортировать экспорт другого.

Сохранение в браузере зависит от браузерного профиля и адреса страницы;
скачанный JSON нужен для переноса и восстановления. Скачивание браузером
не означает автоматическую запись файла в репозиторий.

## Как применить

Новый запуск `intake.py` автоматически создаёт `annotate.html` рядом с кадрами.
Для существующего запуска:

```powershell
python development/src/sanas_video/annotations.py build development/experiments/artifacts/video-intake/demo-20260912
```

Страница не обращается к сторонним сервисам. При необходимости можно открыть
её через локальный сервер, отдающий только папку результата:

```powershell
python -m http.server 8769 --bind 127.0.0.1 --directory development/experiments/artifacts/video-intake/demo-20260912
```

Затем открыть [локальную страницу](http://127.0.0.1:8769/annotate.html).
Сервер доступен только на этом компьютере и работает, пока запущен процесс.
Прямое открытие HTML возможно, но поведение localStorage зависит от браузера;
ручной экспорт JSON предусмотрен и при недоступном хранилище.

После двух независимых разметок выполнить:

```powershell
python development/src/sanas_video/annotations.py compare development/experiments/artifacts/video-intake/demo-20260912 development/experiments/artifacts/video-intake/annotator-ui-check-20260912/rater_a.json development/experiments/artifacts/video-intake/annotator-ui-check-20260912/rater_b.json --output development/experiments/artifacts/video-intake/new-comparison.json
```

В примере указаны искусственные тестовые экспорты; для исследования заменить
папку intake и JSON реальными файлами. Существующий файл результата не перезаписывается.

## Контрольное сравнение

В искусственном UI-тесте разметчик QA_BROWSER_A поставил на первом кадре
две отметки, QA_BROWSER_B — одну. Второй кадр оба подтвердили с нулём.
Третий оставлен неподтверждённым. CLI верно сравнил **две пары**, исключил
третий кадр и получил среднюю абсолютную разность счёта **0,5**, долю точного
совпадения **0,5**. [JSON сравнения](../../development/experiments/artifacts/video-intake/annotator-ui-check-20260912/comparison.json).
Эти числа проверяют арифметику инструмента; они не являются результатами SANASH
по пассажирам, точностью модели или показателем реального согласия людей.

## Ограничения и следующий шаг

Сравнение оценивает общий счёт и распределение отметок по зонам. Оно не
сопоставляет людей между точками/камерами и не доказывает независимость двух
разметчиков лишь по их ID. Доверительные интервалы по соседним кадрам не строятся.
Слепые зоны пока описываются текстом; карта зон конкретного салона и независимый
счёт наблюдателя остаются частью полевого протокола.

Теперь готова цепочка **экспорт видео → кадры → две разметки → отчёт о
расхождениях**. Следующий содержательный вход — разрешённый фрагмент штатной
салонной камеры. Его нет, поэтому реальные показатели видимости и загруженности
по-прежнему не заявляются.
