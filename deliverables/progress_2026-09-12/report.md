## Исправления wave 2

| Проблема в исходном коде | Новое поведение |
|---|---|
| Ошибка одной из 12 таблиц приводила к публикации неполной общей выборки | Оба набора ответов сохраняются; вкладка «Источники» сообщает ошибку; запуск завершается ошибкой |
| Любая дополнительная вкладка master удалялась | Дополнительные вкладки сохраняются |
| Источником выбиралась самая широкая вкладка | Используется единственная вкладка, связанная с формой; отсутствие/неоднозначность — ошибка |
| Результат мог превысить размер сетки Sheets | Перед записью добавляются недостающие строки и столбцы |
| Одновременные обновления могли перемешать запись | Script lock запрещает параллельную синхронизацию |
| Ошибка доступа к существующему master скрывалась созданием нового | Ошибка остаётся видимой; новый master не создаётся |
| Router пытался перенаправить верхнее окно после асинхронного вызова | Появляется явная ссылка на выбранную форму; повторный клик не создаёт новое назначение |

Последняя проблема следует из ограничений sandbox Google; поведение конкретного
развёртывания в браузере пока не проверено.
[Apps Script HTML restrictions](https://developers.google.com/apps-script/guides/html/restrictions).
Выбор вкладки основан на
[Sheet.getFormUrl](https://developers.google.com/apps-script/reference/spreadsheet/sheet#getFormUrl()),
защита от одновременного запуска — на
[LockService](https://developers.google.com/apps-script/reference/lock/lock-service).

## Что ещё не проверено

- Изменения не загружены в Apps Script и не опубликованы в действующем router.
  В локальных файлах URL развёрнутого `/exec` не найден.
- Соответствие каждого опубликованного form ID указанной таблице источника
  требует проверки в аккаунте владельца. Локальный тест проверяет структуру
  конфигурации, а не реальную привязку Google.
- Не проверены действующие настройки D3, ветки отказа/скрининга в опубликованных
  формах, trigger, права и полная цепочка «отправка → источник → master».
- Master остаётся снимком сырых ответов. Отказ от участия и screen-out могут
  быть строками формы; число строк не равно числу участников аналитической выборки.
  ID построен из номера строки и изменится при сортировке/удалении строк источника.
- Сохранение старых ответов защищено при ошибке ЧТЕНИЯ источников. Запись трёх
  вкладок Google не является транзакцией: сбой во время записи всё ещё может
  оставить частичное обновление. Исходные таблицы остаются источником восстановления.
- Физического теста камеры, подключения к автобусу и новых метрик CV нет.
